# Smart Text Poster 浏览器插件

这个项目提供一个 Chrome 通用的浏览器插件，帮助你把复制的文字快速排版成精美海报图片。插件内置多种模板，可用于新闻快报、行业文献分享以及灵感便签等场景，并支持一键下载高清 PNG 图片。

## 功能亮点

- ✨ **多模板选择**：提供新闻、行业分享、灵感便签三种风格，覆盖常见传播场景。
- 🧠 **智能排版**：自动按段落拆分文字，匹配每个模板的最佳排版方式。
- 🖼️ **高清输出**：内置 1080 × 1920 画布，生成高清 PNG，适合朋友圈和公众号。
- 📋 **快捷粘贴**：支持从剪贴板快速粘贴内容，随时整理灵感。
- 💾 **自动记忆**：使用浏览器本地存储记住上一次的模板和填写内容。

## 如何下载插件

1. 打开 GitHub 仓库页面，点击绿色的 **Code** 按钮，然后选择 **Download ZIP**，即可把整个项目下载到本地。
2. 在电脑上找到下载好的压缩包（通常名为 `smart-text-poster-main.zip` 或类似名称），使用系统自带的解压工具（Windows 右键选择“全部提取”，macOS 双击）解压。
3. 解压后会得到一个项目文件夹，进入后可以看到 `extension` 子文件夹，里面就是浏览器插件所需的全部文件。
4. 如果你已经手动生成了其他压缩包，请确保不要把它添加到拉取请求中，只需要保留 `extension` 文件夹里的源文件即可，这样在 GitHub 上就不会再出现“二进制文件不支持预览”的提示。

## 使用指南

1. 打开 Chrome，进入 `chrome://extensions/`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择刚才解压得到的 `extension` 文件夹。
3. 安装后，点击工具栏图标打开插件，粘贴文字、选择模板即可实时预览。
4. 点击“下载图片”按钮，将当前预览导出为 PNG 文件。

## 项目结构

```
extension/
├── manifest.json   # Chrome 扩展清单（使用 Chrome 默认图标，无需二进制资源）
├── popup.html      # 弹窗页面结构
├── popup.css       # 弹窗页面样式
└── popup.js        # 画布绘制与交互逻辑
```

## 本地开发

- 所有模板均基于 Canvas 绘制，修改样式时可直接在 `popup.js` 中调整颜色、排版或新增模板函数。
- 画布尺寸默认 1080 × 1920，如需调整可修改 `popup.html` 中的 `<canvas>` 属性以及相关布局参数。

欢迎按需拓展更多模板或集成图文素材，满足更多分享场景。
